# EcoDash — African Digital Logistics & Infrastructure Simulator

**Module:** WAS262/SF1  
**Technology:** HTML5 Canvas, CSS3, Vanilla JavaScript (ES6+)  
**Scenario:** An electric delivery vehicle carries medical supplies to a rural South African clinic.

## Project description

EcoDash is an educational 2D simulation about sustainable last-mile delivery. The player drives a small electric vehicle along a rural route, avoids damaged-road hazards, monitors battery reserve, recharges at a solar microgrid, and tries to deliver supplies to a clinic. A simulated load-shedding event can temporarily make the charging zone unavailable.

The project is a simplified model for learning purposes. Its speeds, distances, battery values, and blackout timings are game values rather than real-world engineering measurements.

## How to run the project

1. Download or clone this repository.
2. Keep `index.html`, `styles.css`, and `app.js` in the same folder.
3. Open `index.html` in a modern browser such as Chrome or Edge.
4. Click **Start mission**.
5. Use **W/A/S/D** or the arrow keys to move. Press **P** to pause or resume.
6. Drive into the yellow solar zone to recharge when it is available.
7. Reach the clinic to complete the delivery.

No external game engine or JavaScript framework is used.

## Controls

- W / Up Arrow: move north
- S / Down Arrow: move south
- A / Left Arrow: move west
- D / Right Arrow: move east
- P: pause/resume
- Restart mission: reset the current run

## Implemented features

- HTML5 Canvas drawing and a `requestAnimationFrame()` animation loop.
- Object-oriented programming using the `DeliveryVehicle` class.
- Acceleration, velocity, drag, speed limiting, and direction using `Math.atan2()`.
- Battery depletion while moving and recharging in a solar zone.
- Circle-distance collision detection for hazards.
- Axis-aligned bounding-box (AABB) collision detection for the solar zone and clinic.
- Simulated load-shedding that temporarily disables solar charging.
- Score, distance travelled, and a simple energy-efficiency indicator.
- Start, pause, success, failure, and restart states.
- Best-score persistence using browser `localStorage`.
- Responsive layout and an African-inspired rural landscape.
