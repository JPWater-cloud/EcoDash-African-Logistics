## 2. Example prompt used

“Help me plan a beginner-friendly HTML5 Canvas and vanilla JavaScript simulation called EcoDash. It should model an electric delivery vehicle in a South African rural environment and include movement, battery management, solar charging, obstacles, collision detection, scoring, pause/restart, and local storage. Explain the code so I can test and defend it.”

## 3. Summary of the AI response

The response suggested separating the page, styling, and game logic into `index.html`, `styles.css`, and `app.js`. It suggested using a vehicle class, keyboard input, velocity and acceleration, collision detection, a solar charging zone, a simulated blackout, game states, and local storage for a best score.

## 4. Problems or limitations to check

- The game uses simplified battery, distance, speed, and blackout values. They are not measurements from a real vehicle.
- Keyboard controls and collision behaviour need to be tested in the target browser.
- Local storage can be unavailable in some browser/privacy settings.
- The source list must be checked against the actual STADIO Library requirement.
- The initial starter code does not complete the required student-created original feature.
